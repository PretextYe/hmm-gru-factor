# 参考文献

本项目方法复现（并改造）了以下两篇卖方研报，PDF 原文因版权原因不入库，可按标题检索获取。

1. **广发证券**《再探西蒙斯投资之道：基于隐马尔科夫模型的选股策略研究》，2018-09-05。
   → HMM 因子方法：`src/hmm_factor.py` 完整复现其滚动训练 UP/DOWN 双 HMM、
   以 `log P(O|λ_up)` 作为因子的流程（隐状态 N=3、高斯混合 M=2、观测序列 Q=10、调仓周期 L=5）。

2. **申万宏源**《量化策略演进手记系列之三：GRU 选股模型的时序分域探索》，2026-07-14。
   → GRU 模型设定：`src/gru_train.py` 采用其统一模型设定
   （40 日输入窗口、hidden=16、1 层、dropout=0.2、按日截面排序损失），
   并将 HMM 因子（`hmm_factor, logp_up, logp_down`）作为时序特征输入。
